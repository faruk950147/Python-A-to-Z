Scalar বের করার নিয়ম

Scalar কী?
-------------
- Scalar হলো একটি সংখ্যা যা matrix-এর প্রতিটি element-এর সাথে গুণ করা হয়েছে। 
- Scalar সাধারণত integer, fraction বা decimal হতে পারে।

Scalar বের করার step-by-step নিয়ম:
-----------------------------------
ধরা যাক:

A = [ [1, 2],
      [3, 4] ]
B = [ [2, 4],
      [6, 8] ]

এখানে দেখা যাচ্ছে, B হলো A-এর scalar দিয়ে গুণ করা।

Step 1: প্রথম element দেখো:
B[0][0] = 2, A[0][0] = 1

Step 2: Scalar k বের করো:
k = B[0][0] / A[0][0] = 2 / 1 = 2

Step 3: সব element-এ check করো:
- B[0][1] / A[0][1] = 4 / 2 = 2 
- B[1][0] / A[1][0] = 6 / 3 = 2 
- B[1][1] / A[1][1] = 8 / 4 = 2 

ফলে scalar = 2

Shortcut Rule:
---------------
- Scalar বের করতে হলে B-এর কোনো element কে A-এর একই position-এর element দিয়ে ভাগ করলেই scalar পাওয়া যায়।
- সব element check করে একি scalar হচ্ছে কিনা নিশ্চিত করতে হবে।


Matrix Full Notes – ➕➖✖️➗

1. Matrix Addition (যোগ)
-----------------------
শর্ত:
- দুইটি matrix-এর row ও column সমান হতে হবে।

Rule:
- একই পজিশনের element গুলোকে যোগ করতে হবে।
A + B = (a_ij + b_ij)

Example:
A = [ [1, 2],
      [3, 4] ]
B = [ [5, 6],
      [7, 8] ]
A + B = [ [6, 8],
          [10, 12] ]

2. Matrix Subtraction (বিয়োগ)
-----------------------------
শর্ত:
- দুইটি matrix-এর order একই হতে হবে।

Rule:
- একই পজিশনের element গুলোকে বিয়োগ করতে হবে।
A - B = (a_ij - b_ij)

Example:
A = [ [1, 2],
      [3, 4] ]
B = [ [5, 6],
      [7, 8] ]
A - B = [ [-4, -4],
          [-4, -4] ]

3. Scalar Multiplication (সংখ্যা দিয়ে গুণ)
------------------------------------------
Rule:
- প্রতিটি element কে scalar দিয়ে গুণ করতে হবে।
kA = (k × a_ij)

Example:
A = [ [1, 2],
      [3, 4] ]
k = 2
2A = [ [2, 4],
       [6, 8] ]

4. Matrix Multiplication (Matrix × Matrix)
------------------------------------------
শর্ত:
- প্রথম matrix-এর column সংখ্যা = দ্বিতীয় matrix-এর row সংখ্যা।
- যদি A = m × n এবং B = n × p, তাহলে A × B = m × p

Rule:
- Row × Column করে গুণ করে যোগ করতে হবে।
C_ij = Σ a_ik * b_kj

Example:
A = [ [1, 2],
      [3, 4] ]
B = [ [5, 6],
      [7, 8] ]
A × B = [ [19, 22],
          [43, 50] ]

Important:
- Matrix multiplication commutative নয়। সাধারণত A × B ≠ B × A

5. Scalar বের করা (Division / ÷)
--------------------------------
Rule:
- B = k × A হলে, scalar বের করতে B-এর কোনো element কে A-এর একই element দিয়ে ভাগ করো।
- সব element check করে একি scalar হচ্ছে কিনা নিশ্চিত করতে হবে।

Example:
A = [ [1, 2],
      [3, 4] ]
B = [ [2, 4],
      [6, 8] ]

Step by step:
- Top-left: k = B[0][0] / A[0][0] = 2 / 1 = 2
- Top-right: 4 / 2 = 2
- Bottom-left: 6 / 3 = 2
- Bottom-right: 8 / 4 = 2

ফলে scalar = 2

Extra Important Properties
--------------------------
- A + B = B + A
- A × (B + C) = AB + AC
- (AB)C = A(BC)
- k(A + B) = kA + kB
