3. shutil Library    

কি?
Python standard library
High-level file operations (copy, move, delete) করতে ব্যবহার হয়
সুবিধা
os library থেকে সহজ
Folder copy/move/delete দ্রুত করে
File backup & organize করতে ব্যবহার হয়

Common Methods
Method	কাজ
shutil.copy(src, dst)	ফাইল copy করা
shutil.copytree(src, dst)	পুরো folder copy করা
shutil.move(src, dst)	ফাইল বা folder move করা
shutil.rmtree(path)	পুরো folder delete করা
উদাহরণ:
import shutil

# File copy
shutil.copy("source.txt", "destination.txt")

# Folder copy
shutil.copytree("my_folder", "backup_folder")

# File move
shutil.move("file.txt", "new_folder/file.txt")

# Delete folder
shutil.rmtree("old_folder")
4. File Automation Example
import os
import shutil

source_folder = "files"
backup_folder = "backup"

# Backup folder create
if not os.path.exists(backup_folder):
    os.mkdir(backup_folder)

# Rename & move files
for count, filename in enumerate(os.listdir(source_folder)):
    old_path = os.path.join(source_folder, filename)
    new_name = f"file_{count}.txt"
    new_path = os.path.join(backup_folder, new_name)
    shutil.move(old_path, new_path)

print("Files successfully moved & renamed!")

কাজ:

সব file rename করে backup_folder-এ move করবে
