🖥 1. File & Folder Automation


ফাইল rename, move, copy, delete স্বয়ংক্রিয়ভাবে


ডিরেক্টরিতে নতুন ফাইল এলে সেটি detect করা


Example: os, shutil, pathlib মডিউল ব্যবহার


🧾 2. Excel / CSV Automation


Excel ডাটা পড়া, পরিবর্তন করা, ফিল্টার করা


Auto রিপোর্ট তৈরি করা


Libraries: openpyxl, pandas, xlrd


🌐 3. Web Automation (Browser Control)


ওয়েবসাইটে login করা


Form submit, data scrape করা


Libraries: selenium, requests, BeautifulSoup, playwright


💌 4. Email Automation


Email send/receive করা


Daily report পাঠানো


Libraries: smtplib, email, imaplib


🕒 5. Task Scheduling


নির্দিষ্ট সময় পরপর কোনো কাজ চালানো


Library: schedule, time, cron (Linux)


🤖 6. Desktop Automation


Keyboard ও Mouse দিয়ে কোনো প্রোগ্রাম চালানো


Screenshot নেওয়া, click করা


Libraries: pyautogui, pynput


🧠 7. Data Automation


ডাটা scrape করে database-এ সংরক্ষণ করা


রিপোর্ট জেনারেট করা


Libraries: pandas, sqlalchemy, requests



💡 একটা ছোট উদাহরণ:
import os

folder = "C:/Users/Faruk/Desktop/Images"
for i, file in enumerate(os.listdir(folder)):
    old_name = os.path.join(folder, file)
    new_name = os.path.join(folder, f"image_{i+1}.jpg")
    os.rename(old_name, new_name)

print("সব ফাইল rename হয়ে গেছে!")

🔹 এই স্ক্রিপ্টটা স্বয়ংক্রিয়ভাবে ফোল্ডারের সব ইমেজ rename করে দেবে।
