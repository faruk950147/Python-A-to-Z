Playwright Full Notes
1. Playwright কি?

Playwright হলো Python library যা browser automation ও testing-এর জন্য ব্যবহৃত হয়।

Supports: Chrome, Firefox, Safari, Edge
Use: Web scraping, automation, testing

2. Installation
pip install playwright
playwright install
3. Basic Setup
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()
    page.goto("https://example.com")
    print(page.title())
    browser.close()
4. Browser Types
p.chromium.launch()
p.firefox.launch()
p.webkit.launch()
Chromium = Chrome/Edge
Firefox = Firefox
Webkit = Safari
5. Element Selectors
page.query_selector("css=button")
page.query_selector("#id")
page.query_selector(".class")
page.query_selector("text=Submit")
6. Actions on Elements
page.fill("#username", "admin")
page.click("#login")
page.hover("#menu")
page.check("#checkbox")
page.select_option("#dropdown", "Bangladesh")
7. Extract Text / Attributes
element = page.query_selector("h1")
print(element.text_content())

link = page.query_selector("a")
print(link.get_attribute("href"))
8. Waits
page.wait_for_selector("#username")
Playwright auto-waits by default
Use explicit waits if needed
9. Screenshots & PDFs
page.screenshot(path="screenshot.png")
page.pdf(path="page.pdf")
10. Navigation
page.goto("https://example.com/page2")
page.go_back()
page.go_forward()
page.reload()
11. Handling Multiple Pages / Tabs
page2 = browser.new_page()
page2.goto("https://example.com")
page2.close()
12. Headless / Headful
browser = p.chromium.launch(headless=True)  # Headless
browser = p.chromium.launch(headless=False) # Headful
13. JavaScript Execution
page.evaluate("() => alert('Hello')")
14. Loop Example (Scraping Multiple Items)
items = page.query_selector_all(".product")
for item in items:
    print(item.text_content())
15. Auto-waiting & Robustness
Playwright auto-waits for elements before actions
Less need for sleep() or explicit waits
16. Advantages over Selenium
Feature	Playwright	Selenium
Speed	Faster	Slower
JS Handling	Full	Needs extra wait
Browser support	Chromium, Firefox, WebKit	Most browsers
Headless	Easy	Yes, but needs options
API	Modern async/sync	Older API
17. Example: Login Automation
from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()
    page.goto("https://example.com/login")
    
    page.fill("#username", "admin")
    page.fill("#password", "1234")
    page.click("#login")
    
    print(page.title())
    browser.close()
18. Best Practices
Use sync or async consistently
Auto-wait reduces flaky scraping
Use headless mode in production
Always close browser to free resources
