Basic Code Example
from selenium import webdriver

driver = webdriver.Chrome()

driver.get("https://www.google.com")

print(driver.title)

driver.quit()
Element Find করার উপায়
1. ID দিয়ে
driver.find_element("id", "email")
2. Name দিয়ে
driver.find_element("name", "password")
3. XPath দিয়ে
driver.find_element("xpath", "//input[@type='text']")
4. CSS Selector
driver.find_element("css selector", ".class_name")
Action (User Interaction)
Click
driver.find_element("id", "login").click()
Send Keys (Input)
driver.find_element("name", "email").send_keys("test@gmail.com")
Wait (Important)

Implicit Wait
driver.implicitly_wait(10)
Explicit Wait
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

WebDriverWait(driver, 10).until(
    EC.presence_of_element_located((By.ID, "email"))
)
Browser Options
from selenium.webdriver.chrome.options import Options

options = Options()
options.add_argument("--headless")

driver = webdriver.Chrome(options=options)

Headless mode = Browser open না হয়ে background এ run

Screenshot নেওয়া
driver.save_screenshot("page.png")
Navigation
driver.back()
driver.forward()
driver.refresh()
Multiple Tabs Handle
driver.switch_to.window(driver.window_handles[1])
Cookies Handle
driver.get_cookies()
driver.add_cookie({"name": "test", "value": "123"})

Pro Tips (Important)

Always use Explicit Wait
XPath avoid করে CSS selector use করো
Headless mode production এ use করো
Try-catch না চাইলে condition check করো (তোমার preference অনুযায়ী)
