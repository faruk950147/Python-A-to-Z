1. Web Crawling কী?

Web Crawling হচ্ছে এক ধরণের Automated Program যা ইন্টারনেটে থাকা ওয়েবসাইটের পেজগুলো systematicভাবে ভিজিট করে তথ্য সংগ্রহ করে। এই প্রক্রিয়ায় মূল লক্ষ্য হলো ওয়েবসাইটের URLs খুঁজে বের করা এবং ইন্ডেক্স তৈরি করা।

উদাহরণ:

Google Bot বা অন্যান্য সার্চ ইঞ্জিনের ক্রলার ওয়েবসাইটের পেজগুলো ক্রল করে এবং তাদের সার্চ ইন্ডেক্সে যোগ করে।

বৈশিষ্ট্য:

স্বয়ংক্রিয়ভাবে এক পেজ থেকে অন্য পেজে লিঙ্ক অনুসরণ করে যায়।

মূলত URL বা পেজ স্ট্রাকচার বের করার জন্য ব্যবহৃত হয়।

সাধারণত ডাটা স্টোরেজ বা প্রক্রিয়াকরণের জন্য নয়, বরং ডাটার উৎস খুঁজে পাওয়ার জন্য।

ব্যবহার:

সার্চ ইঞ্জিনে ইনডেক্স তৈরি করা (Google, Bing)

ওয়েব বিশ্লেষণ বা রিসার্চ

ওয়েবের বড় স্কেল বিশ্লেষণ

2. Web Scraping কী?

Web Scraping হচ্ছে প্রক্রিয়া যেখানে কোন ওয়েবসাইট থেকে সরাসরি ডাটা (যেমন টেক্সট, ইমেজ, প্রাইস, টেবিল) বের করা হয়। এটা মূলত ডাটা এক্সট্র্যাকশন এর জন্য করা হয়।

উদাহরণ:

একটি ই-কমার্স সাইট থেকে প্রোডাক্টের নাম, দাম, এবং রেটিং বের করা।

নিউজ সাইট থেকে আর্টিকেল, তারিখ, লেখকের নাম সংগ্রহ করা।

বৈশিষ্ট্য:

নির্দিষ্ট ডাটা বা কনটেন্ট টার্গেট করে নেওয়া হয়।

সাধারণত HTML structure বা API ব্যবহার করে ডাটা বের করা হয়।

ক্রলার ব্যবহার করা যেতে পারে, কিন্তু scraping মূলত ডাটা প্রসেসিং এবং এক্সট্র্যাকশনের জন্য।

ব্যবহার:

মার্কেট রিসার্চ (দাম তুলনা)

ডাটা অ্যানালাইসিস (ফাইনান্স, রিয়েল এস্টেট)

প্রোডাক্ট মনিটরিং

নিউজ বা সোশ্যাল মিডিয়া ডাটা এক্সট্র্যাকশন

3. Web Crawling vs Web Scraping – তুলনামূলক বিশ্লেষণ
বিষয়	Web Crawling	Web Scraping
উদ্দেশ্য	ওয়েব পেজ এবং URL খোঁজা	ওয়েব পেজ থেকে নির্দিষ্ট ডাটা বের করা
মূল ব্যবহার	সার্চ ইঞ্জিন ইনডেক্সিং, লিঙ্ক ম্যাপিং	ডাটা এক্সট্র্যাকশন, বিশ্লেষণ, রিপোর্টিং
লক্ষ্য	ওয়েবের স্ট্রাকচার জানা	ওয়েবের কনটেন্ট বা তথ্য জানা
প্রক্রিয়া	এক পেজ থেকে লিঙ্ক অনুসরণ করা	টার্গেট পেজ থেকে HTML বা API ডাটা বের করা
ডাটা প্রক্রিয়াকরণ	কম	বেশি (ডাটা প্রিপ্রসেসিং বা স্টোরেজ প্রয়োজন হতে পারে)
উদাহরণ	Google Bot	Python BeautifulSoup, Scrapy, Selenium
4. কেন ব্যবহার করা হয়?
Web Crawling:

ওয়েব পেজের লিঙ্ক খুঁজে বের করতে

সার্চ ইঞ্জিনের জন্য ইনডেক্স তৈরি করতে

ওয়েব বিশ্লেষণ বা রিসার্চের জন্য

Web Scraping:

নির্দিষ্ট ডাটা সংগ্রহ করতে (Product info, News, Prices)

ডাটা অ্যানালাইসিস বা BI (Business Intelligence)

স্বয়ংক্রিয় রিপোর্ট তৈরি করতে

মোট কথা:

Crawling = ওয়েবের মানচিত্র তৈরি করা।

Scraping = ওয়েবের তথ্য সংগ্রহ করা।

Crawling প্রায়ই Scraping এর জন্য একটি স্টেপ হিসেবে ব্যবহৃত হয়।
