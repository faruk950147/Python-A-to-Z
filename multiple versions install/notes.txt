Python 3.7.9 এবং 3.14.2 আছে। (যদি আপনি আসলে Python 3.14 বলতে চাচ্ছেন, তাহলে মনে রাখবেন Python 3.14 এখন experimental / alpha stage, কিন্তু আমরা process একদম একইভাবে handle করতে পারি।)

একই কম্পিউটারে Python 3.7.9 ও 3.14.2 একসাথে ব্যবহার করবেন, step-by-step।

Step 1: Python versions download করা

Python official site থেকে চাইতে পারেন:

Python 3.7.9

Python 3.14.x
 (Alpha/Pre-release)

Windows-এর জন্য .exe installer, Linux-এর জন্য apt বা yum অথবা source build করুন।

Step 2: Install করার সময় আলাদা path দিন

Windows:

Install location আলাদা দিন:

C:\Python379\
C:\Python314\


Install-এর সময় “Add Python to PATH” check করুন।

Linux:

Linux-এ সাধারণভাবে Python version /usr/bin/python3.7 বা /usr/local/bin/python3.14 এ install হবে।

Step 3: Python versions verify করা
# Windows
py -3.7 --version
py -3.14 --version

# Linux
python3.7 --version
python3.14 --version


দেখাবে কোন version ঠিকভাবে install হয়েছে।

Step 4: Version switch করা

Windows:

py -3.7
py -3.14


Linux:

sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.7 1
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.14 2
sudo update-alternatives --config python3


Menu থেকে default version select করতে পারবেন।

Step 5: Virtual environment ব্যবহার করা (Recommended)

Project-specific Python version চাইলে virtual environment তৈরি করুন:


আসলে এই ভুলটা হওয়ার পেছনে একটা সূক্ষ্ম টেকনিক্যাল কারণ আছে। সহজ করে বললে:

python এবং py — এই দুটি কমান্ড উইন্ডোজে আলাদাভাবে কাজ করে।

১. python কমান্ডের সীমাবদ্ধতা:
যখন আপনি টার্মিনালে python লেখেন, তখন উইন্ডোজ সরাসরি python.exe ফাইলটি খোঁজে। এই ফাইলটির নিজস্ব কিছু "Options" বা "Arguments" থাকে (যেমন: -m, -c, -v)। কিন্তু পাইথনের মেইন ফাইলে -3.7 নামে কোনো অপশন নেই। তাই যখন আপনি python -3.7 লিখছেন, পাইথন মনে করছে আপনি তাকে ভুল কোনো কমান্ড দিচ্ছেন, তাই সে Unknown option: -3 এররটি দেখাচ্ছে।

২. py (Python Launcher) এর কাজ:
উইন্ডোজে যখন আপনি একাধিক পাইথন ভার্সন ইনস্টল করেন, তখন একটি ছোট প্রোগ্রাম ইনস্টল হয় যার নাম Python Launcher। এর কমান্ড হলো শুধু py।

py কমান্ডটির কাজই হলো আপনার পিসিতে থাকা বিভিন্ন পাইথন ভার্সনগুলোর মধ্যে সমন্বয় করা।

শুধুমাত্র এই py কমান্ডটিই বোঝে যে -3.7 মানে হলো "পাইথন ৩.৭ ভার্সনটি ব্যবহার করো"।

একটি উদাহরণ দিয়ে বুঝাই:
ভুল: python -3.7 -m venv env (এখানে আপনি সরাসরি পাইথনকে বলছেন নিজের একটা ভার্সন খুঁজে নিতে, যা সে পারে না।)

সঠিক: py -3.7 -m venv env (এখানে আপনি 'লঞ্চার' বা ম্যানেজারকে বলছেন পাইথন ৩.৭ ব্যবহার করে এনভায়রনমেন্ট তৈরি করতে।)

সহজ কথা হলো: একবার এনভায়রনমেন্ট তৈরি হয়ে গেলে এবং আপনি সেটি Activate করে ফেললে, তখন আর py ব্যবহার করতে হবে না। তখন শুধু python লিখলেই হবে, কারণ অ্যাক্টিভেট থাকা অবস্থায় সিস্টেম জানে আপনি কোন ভার্সনটি ব্যবহার করছেন।

আপনার কি py -3.7 -m venv env379 কমান্ডটি এখন কাজ করেছে?


Windows:
py -3.7 -m venv env379
py -3.14 -m venv env314

Activate করুন:

# Windows
env379\Scripts\activate
env314\Scripts\activate

# Linux/Mac
Linux:
source env379/bin/activate
source env314/bin/activate



এখন active environment-এর Python এবং packages ব্যবহার হবে।


সবসময় python3.x -m pip install package_name ব্যবহার করুন।

Virtual environment ব্যবহার করলে dependency conflict হবে না।
