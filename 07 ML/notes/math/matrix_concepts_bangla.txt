১. অনুরাশি (Minor)

কোনো Matrix-এর একটি উপাদানের Minor হলো— ঐ উপাদান যে সারি (row) ও স্তম্ভ
(column)-এ আছে, তা বাদ দিয়ে যে নতুন ম্যাট্রিক্স পাওয়া যায় তার Determinant।

উদাহরণ: A = [1 2 3 4 5 6 7 8 9]

a11 = 1

প্রথম row ও column বাদ দিলে: [5 6 8 9]

M11 = (5×9) − (6×8) = −3

২. Matrix এর অনুরূপ সহগুণক (Cofactor) কী?

কোনো উপাদানের Cofactor পাওয়া যায় Minor-এর সাথে চিহ্ন যোগ করে।

সূত্র: Cij = (−1)^(i+j) × Mij

যেখানে,

Mij = Minor
i = Row নম্বর
j = Column নম্বর

চিহ্নের প্যাটার্ন:

উদাহরণ: M12 = 7 হলে, C12 = −7
[+ - +]
[− + −]
[+ - +]


উদাহরণ:

যদি M12 = 7

তাহলে

C12 = (−1)^(1+2) × 7 = −7


৩. Matrix এর Adjoint / Adjugate কী?

কোনো Matrix-এর সব Cofactor নিয়ে নতুন Matrix তৈরি করে তারপর সেটির Transpose করলে তাকে Adjoint (Adjugate) বলে।

সূত্র:

Adj(A)=[Cij]T

অর্থাৎ:

Adj(A)=Transpose of Cofactor Matrix

ধাপ:

Minor বের করো
Cofactor বের করো
Cofactor Matrix বানাও
Transpose করো

উদাহরণ:

A=[a c
  b d]

তাহলে,

Adj(A)=[d -c
      -b a]

৪. Matrix এর Determinant কী?

Determinant হলো একটি সংখ্যা (scalar value) যা একটি Square Matrix থেকে বের করা হয়।

২×২ Matrix:

A=[a c
  b d]

Determinant: ∣A∣=ad−bc

উদাহরণ: [2 4
         3 5]

∣A∣=(2×5)−(3×4)
=10−12=−2

ব্যবহার:

Matrix inverse বের করতে
সমীকরণ সমাধান করতে
Linear algebra-তে

৫. Matrix Multiplication (গুণন) কী?

দুইটি Matrix গুণ করা যায় যদি—

প্রথম Matrix-এর Column সংখ্যা = দ্বিতীয় Matrix-এর Row সংখ্যা

শর্ত: প্রথম Matrix-এর Column = দ্বিতীয় Matrix-এর Row

সূত্র: (AB)ij = Σ(aik × bkj)

শর্টকাট: Minor → Row + Column বাদ দিয়ে Determinant Cofactor → Minor ×
(−1)^(i+j) Adjoint → Cofactor Matrix-এর Transpose Determinant →
Matrix-এর মান Multiplication → Row × Column
