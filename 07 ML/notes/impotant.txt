1. Outlier

Dataset-এর এমন data point যা অন্য data point থেকে অস্বাভাবিকভাবে দূরে থাকে।

Example:
Salary = 10k, 12k, 11k, 500k → এখানে 500k হলো outlier।

Problem:

Mean ও variance distort করতে পারে
কিছু model (যেমন Linear Regression) ভুল trend শিখতে পারে

Common handling:
Remove, clipping, transformation, robust scaling

2. Linear Relationship

যখন দুইটি variable-এর মধ্যে প্রায় সরলরেখার মতো সম্পর্ক থাকে।

Example:
Study Time ↑ → Marks ↑

এটা হতে পারে:

Positive Linear → একসাথে বাড়ে
Negative Linear → একটা বাড়লে অন্যটা কমে

Problem (যদি না থাকে):
Linear model (যেমন Linear Regression) ভালো perform নাও করতে পারে।

3. Multicollinearity (Feature Problem)

যখন দুই বা ততোধিক feature নিজেদের মধ্যে খুব বেশি correlated থাকে।

Example:

Height (cm)
Height (inch)

Problem:

Feature importance unstable হয়
Coefficient interpret করা কঠিন হয়
Regression model-এর performance খারাপ হতে পারে

Detection:
Correlation Matrix, VIF

4. Class Imbalance (Classification)

যখন dataset-এ কিছু class অনেক বেশি এবং কিছু class খুব কম থাকে।

Example:
99% Not Fraud
1% Fraud

Problem:
Model সবসময় majority class predict করতে পারে।

Solution:

Oversampling
Undersampling
SMOTE
Class Weight
5. Overlapping Classes

যখন বিভিন্ন class-এর feature space একে অপরের সাথে মিশে যায়।

Example:
কিছু Cat এবং Dog image-এর feature অনেক similar।

Problem:
Decision boundary clear হয় না → accuracy কমে।

Solution:

Better features
More data
Complex model (Random Forest, Neural Network)
6. Distribution Problem (Diagonal Plot / Feature Distribution)

যখন data normal distribution follow না করে skewed বা uneven হয়।

Example:
Income data → অনেক low income, কম high income → Right Skew

Problem:
কিছু model distribution sensitive হতে পারে।

Detection:

Histogram
Pairplot diagonal
KDE Plot

Solution:

Log Transform
Standardization
Normalization

এগুলো ML-এর EDA (Exploratory Data Analysis)-এ খুব common concepts।

Multicollinearity চেক করার জন্য Heatmap (যা তুমি এখনই করতে যাচ্ছ)কোড তো রেডিই আছে: sns.heatmap(df.corr(), annot=True, cmap='coolwarm') রান করলেই ম্যাট্রিক্স চলে আসবে।যা খুঁজবে: যদি কোনো দুটি ফিচারের মধ্যে কোরিলেশন স্কোর $0.75$ থেকে $0.90$-এর উপরে থাকে (যেমন টাইটানিক ডেটাসেটে অনেক সময় SibSp আর Parch বা Pclass আর Fare-এর মধ্যে কোরিলেশন দেখা যায়), তবে একটি ফিচার ড্রপ করার কথা ভাবা যেতে পারে।২. Outlier হ্যান্ডেল করা (Fare কলামের জন্য)শনাক্তকরণ: তুমি একদম ঠিক ধরেছ, sns.boxplot(y=df['Fare']) দিলেই আউটলায়ারগুলো স্পষ্ট ভেসে উঠবে।সমাধান: যেহেতু টাইটানিকে কিছু মানুষ আসলেই অনেক দামি টিকিট কেটেছিল, তাই এগুলোকে সরাসরি ড্রপ না করে IQR (Interquartile Range) Method দিয়ে ক্লিপ (cap) করে দেওয়া বা Log Transformation করাটাই বুদ্ধিমানের কাজ হবে।৩. Distribution ঠিক করা (Skewness দূর করা)সমাধান: Fare কলামের skewness দূর করতে তোমার দেওয়া কোডটিই বেস্ট: np.log1p(df['Fare'])। এটা ডেটাকে নরমাল ডিস্ট্রিবিউশনের কাছাকাছি নিয়ে আসবে, যা লিনিয়ার বা লজিস্টিক রিগ্রেশনের মতোモデルগুলোর পারফরম্যান্স অনেক বাড়িয়ে দেয়।৪. Class Imbalance (Survived কলাম)অবস্থা: যেহেতু অনুপাতটা একেবারে $99:1$ নয় (টাইটানিকে সাধারণত $60:40$ বা $62:38$ এর আশেপাশে থাকে), তাই এটাকে Moderate Imbalance বলা যায়।সমাধান: এর জন্য খুব বেশি জটিল টেকনিক (যেমন SMOTE) না লাগলেও চলে। শুধু মডেল ট্রেন করার সময় StratifiedKFold ক্রস-ভ্যালিডেশন ব্যবহার করলে এবং ইভ্যালুয়েশনের জন্য শুধু Accuracy-র ওপর ভরসা না করে F1-Score ও ROC-AUC চেক করলেই হবে।তুমি একদম সঠিক ট্র্যাকে আছ। এখন Heatmap-এর স্ক্রিনশটটি দাও, কোন কোন ফিচারের মধ্যে কলিশন বা multicollinearity আছে, সেটা সুনির্দিষ্টভাবে বের করে ফেলছি!
