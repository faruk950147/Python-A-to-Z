Pandas Notes with Description (Bangla)
1️⃣ Import
import pandas as pd

Description: Pandas ব্যবহার করার জন্য প্রথমে import করতে হবে। pd নামটা standard convention।

2️⃣ Data Creation
Function	Description	Example
pd.DataFrame()	Dictionary/List থেকে DataFrame তৈরি	df = pd.DataFrame({"Name":["Ali","Hasan"], "Age":[20,22]})
pd.Series()	1-Dimensional array তৈরি	s = pd.Series([1,2,3])
pd.concat()	একাধিক DataFrame/Series জোড়া	pd.concat([df1, df2])
pd.merge()	SQL style join	pd.merge(df1, df2, on="id")
pd.get_dummies()	Categorical → One Hot Encoding	pd.get_dummies(df["Category"])
pd.cut()	Continuous data কে bins এ ভাগ করা	pd.cut(df["Age"], bins=3)
pd.qcut()	Quantile ভিত্তিক bins	pd.qcut(df["Age"], q=4)
3️⃣ Data Reading (লোড করা)
Function	Description	Example
pd.read_csv()	CSV ফাইল থেকে DataFrame তৈরি	df = pd.read_csv("file.csv")
pd.read_excel()	Excel ফাইল থেকে DataFrame	df = pd.read_excel("file.xlsx", sheet_name="Sheet1")
pd.read_json()	JSON ফাইল থেকে DataFrame	df = pd.read_json("file.json")
pd.read_html()	HTML table scrape করে	dfs = pd.read_html("file.html")
pd.read_sql()	SQL query থেকে DataFrame	df = pd.read_sql(query, conn)
pd.read_parquet()	Parquet file পড়া (efficient)	df = pd.read_parquet("file.parquet")
pd.read_pickle()	Pickle file পড়া	df = pd.read_pickle("file.pkl")

6️⃣ Data Cleaning
Function	Description	Example
df.isnull()	Null value check	df.isnull().sum()
df.notnull()	Null নেই check	df.notnull()
df.dropna()	Null row drop	df.dropna()
df.fillna()	Null fill	df["Age"].fillna(df["Age"].mean())
df.replace()	Value replace	df.replace("old","new")
df.duplicated()	Duplicate check	df.duplicated()
df.drop_duplicates()	Duplicate drop	df.drop_duplicates()
df.astype()	Data type change	df["Age"].astype("int")
7️⃣ Selection & Filtering
Function	Description	Example
df.loc[]	Label-based selection	df.loc[2,"Name"]
df.iloc[]	Index-based selection	df.iloc[2,1]
df.at[]	Single value access	df.at[2,"Name"]
df.iat[]	Fast single value access	df.iat[2,1]
df.query()	SQL style filtering	df.query("Age>20")
df.filter()	Column/row filter	df.filter(items=["Name","Age"])
8️⃣ Sorting
Function	Description	Example
df.sort_values()	Column অনুযায়ী sort	df.sort_values("Age")
df.sort_index()	Index অনুযায়ী sort	df.sort_index()
df.nlargest()	বড় n value	df.nlargest(3,"Age")
df.nsmallest()	ছোট n value	df.nsmallest(3,"Age")
9️⃣ Column Operations
Function	Description	Example
df.insert()	নতুন column insert	df.insert(2,"NewCol",[1,2])
df.assign()	নতুন column তৈরি	df.assign(NewCol=lambda x:x.Age+1)
df.drop()	Column/row drop	df.drop("NewCol", axis=1)
df.rename()	Column rename	df.rename(columns={"Name":"FullName"})
df.set_index()	Column → index	df.set_index("Name")
df.reset_index()	Index reset	df.reset_index()
🔟 GroupBy & Aggregation
Function	Description	Example
df.groupby()	Group তৈরি	df.groupby("Dept")["Salary"].mean()
df.agg()	Aggregate function	df.agg({"Salary":"sum","Age":"mean"})
df.transform()	Groupwise transformation	df.groupby("Dept")["Salary"].transform("mean")
df.apply()	Custom function apply	df.apply(lambda x:x*2)
1️⃣1️⃣ Reshaping
Function	Description	Example
df.pivot()	Table reshape	df.pivot(index="Dept", columns="Year", values="Salary")
df.pivot_table()	Aggregated pivot	df.pivot_table(index="Dept", values="Salary", aggfunc="mean")
df.melt()	Wide → Long	df.melt(id_vars=["Dept"], value_vars=["Salary","Bonus"])
df.stack()	Column → Row	df.stack()
df.unstack()	Row → Column	df.unstack()

1️⃣6️⃣ Tips & Rules

বড় dataset → vectorized operation, avoid loops

Missing value → numeric: mean/median, categorical: mode

apply() vs transform() → groupwise calculation use transform

Parquet → faster & memory-efficient

সবসময় df.info() + df.describe() + null check দিয়ে শুরু করো
