Data Cleaning কী?

Data Cleaning মানে হলো —
    Raw ডাটা থেকে ভুল, ফাঁকা, duplicate, inconsistent জিনিসগুলো ঠিক করা।

কারণ:
Dirty Data = Wrong Model
Clean Data = Better Accuracy

Data Cleaning এর Main Step গুলো
1. Missing Value Handle করা
Problem:
    কিছু কলামে value নাই (NaN / NULL)

Solution:
import pandas as pd

df.isnull().sum()
Fix করার উপায়:
Drop করা:
df.dropna(inplace=True)

Mean দিয়ে fill করা:
df["age"].fillna(df["age"].mean(), inplace=True)

Mode দিয়ে:
df["city"].fillna(df["city"].mode()[0], inplace=True)

2. Duplicate Data Remove করা
df.duplicated().sum()
df.drop_duplicates(inplace=True)

3. Wrong Data Type Fix করা
df.dtypes

Example:

df["date"] = pd.to_datetime(df["date"])
df["price"] = df["price"].astype(float)

4. Outlier Detect করা
import matplotlib.pyplot as plt

plt.boxplot(df["salary"])
plt.show()

Outlier remove:

Q1 = df["salary"].quantile(0.25)
Q3 = df["salary"].quantile(0.75)

IQR = Q3 - Q1

df = df[(df["salary"] >= Q1 - 1.5*IQR) & 
        (df["salary"] <= Q3 + 1.5*IQR)]

5. String Data Clean করা
df["name"] = df["name"].str.lower()
df["name"] = df["name"].str.strip()

============================================= Strategy for Missing Value =============================================
Data Cleaning এ এটা খুব common decision। কত % Missing হলে Row বা Column Delete করবো?

এটার fixed rule নাই, কিন্তু practical industry guideline আছে

1. Column Delete করার Rule
Missing %	Decision
0-5%	Keep (fill করা ভালো)
5-20%	Imputation (mean/median/mode)
20-40%	Careful decision (feature importance দেখো)
40-50%	সাধারণত Column drop
60-70%	সাধারণত Column drop

যদি 50% এর বেশি data missing থাকে, সাধারণত column remove করা হয়
কারণ ওই feature reliable না।

2. Row Delete করার Rule
Missing per Row	Decision
1-2 field missing	Fill করা ভালো
অনেক column missing	Row drop করা যায়
50%+ field missing	Row drop safe

Small Dataset হলে
→ Row delete করলে data কমে যাবে
→ তাই fill করা ভালো
Large Dataset হলে
→ Row delete safe

Real Example
ধরো dataset এ 10,000 row আছে
একটা column এ 6,500 missing value আছে

6500 / 10000 = 65%
এটা drop করাই ভালো।

Pandas দিয়ে Missing % বের করার Code
missing_percent = df.isnull().mean() * 100
print(missing_percent)

Advanced Tip (ML এর জন্য)
যদি feature খুব important হয় (যেমন salary, age)
তাহলে 40% missing হলেও:
✔ Model based imputation
✔ KNN imputer
✔ Predictive filling

ব্যবহার করা যায়।

Final Short Rule

Column > 50% missing → Drop
Row > 50% missing → Drop
Otherwise → Fill

Column এ 50% এর বেশি missing থাকলে drop করা safe

3. Row Delete করার Rule
Condition	Decision
1-2 field missing	Fill করা ভালো
অনেক column missing	Row drop করা যায়
Row এর 50%+ field missing	Drop safe


Short Rule:
Row এর অর্ধেকের বেশি value missing হলে row delete করা যায়

4. Dataset Size Important
Small Dataset হলে:
Row delete করলে data কমে যাবে তাই fill করা ভালো
Large Dataset হলে:
Row delete safe

5. Missing % বের করার Pandas Code

import pandas as pd

# Load dataset
df = pd.read_csv('messy_sales_data.csv')

# 1st: See basic info
# print(df.info())

# 2nd: Check null values
# print(df.isnull().sum())

# 3rd Remove rows where critical fields missing
df.dropna(subset=['Order ID', 'Salesperson', 'Notes'], inplace=True)

# 4rd Fill remaining null values
df['Customer Name'] = df['Customer Name'].fillna('Unknown')
df['City'] = df['City'].fillna('Unknown')
df['Payment Method'] = df['Payment Method'].fillna('Unknown')
df['Status'] = df['Status'].fillna('Pending')

# 5rd Convert data types
numeric_cols = ['Quantity', 'Unit Price', 'Total Amount']

for col in numeric_cols:
    df[col] = pd.to_numeric(df[col], errors='coerce')

df['Order Date'] = pd.to_datetime(df['Order Date'], errors='coerce')
# change to date format
df['Order Date'] = df['Order Date'].dt.strftime('%d-%m-%Y')

# Remove rows where numeric conversion failed
df.dropna(subset=numeric_cols, inplace=True)

# Remove negative values
df = df[(df['Quantity'] > 0) & (df['Unit Price'] > 0)]

# Recalculate Total Amount
df['Total Amount'] = df['Quantity'] * df['Unit Price']

# 6rd Check duplicate rows & columns
# Duplicate rows
# print(df.duplicated().sum())

# Duplicate Order ID
# print(df['Order ID'].duplicated().sum())

# 7rd Remove duplicate rows
df.drop_duplicates(inplace=True)
df.drop_duplicates(subset='Order ID', inplace=True)

# 8rd Standardize text formatting
df['Customer Name'] = df['Customer Name'].str.strip().str.title()
df['Category'] = df['Category'].str.strip().str.upper()
df['Product'] = df['Product'].str.strip().str.title()
df['City'] = df['City'].str.strip().str.title()
df['Payment Method'] = df['Payment Method'].str.strip().str.title()
