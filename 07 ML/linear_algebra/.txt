Gaussian Elimination (Step Explanation)

Given Matrix:

[ 1   2   0  -1 ]
[ 3   4   1   2 ]
[ -2  3   2   5 ]

Step 1:
Take the first element (1) as the pivot.

Goal:
Make all numbers below the pivot equal to 0.

The first column is:

1
3
-2

We need to change 3 into 0.

The row operation is:

R2 → R2 - 3R1

This is the same as:

R2 → (-3)R1 + R2

First, multiply Row 1 by 3:

3R1 = [3  6  0  -3]

Now subtract it from Row 2:

R2 = [3  4  1  2]
     -
     [3  6  0 -3]
     --------------
     [0 -2  1  5]

So the new Row 2 becomes:

[0  -2  1  5]

The matrix is now:

[ 1   2   0  -1 ]
[ 0  -2   1   5 ]
[ -2  3   2   5 ]

Next, make -2 (in Row 3, first column) equal to 0 using:

R3 → R3 + 2R1

This process is called Gaussian Elimination.

Purpose:
Use row operations to convert the matrix into an upper triangular form, making it easier to solve the system of equations.
