# Matrix (ম্যাট্রিক্স) – Full Notes

## ১. Minor (অনুরাশি)

কোনো Matrix-এর একটি উপাদানের Minor হলো— ঐ উপাদানের Row এবং Column বাদ দিয়ে যে নতুন Matrix পাওয়া যায় তার Determinant।

সূত্র:

Mij = Determinant of submatrix after removing row i and column j

উদাহরণ:

A = [
[10, 20, 30]
[40, 50, 60]
[70, 80, 90]
]

M11 বের করতে:

D = [
[50, 60]
[80, 90]
]

|D| = (50×90) − (60×80)

= 4500 − 4800

= -300

অতএব,

M11 = -300

---

## ২. Cofactor (অনুরূপ সহগুণক)

Minor-এর সাথে চিহ্ন যোগ করলে Cofactor পাওয়া যায়।

সূত্র:

Cij = (-1)^(i+j) × Mij

Sign Pattern:

[ +  -  + ]
[ -  +  - ]
[ +  -  + ]

উদাহরণ:

যদি M12 = 7

তাহলে

C12 = (-1)^(1+2) × 7

= -7

---

## ৩. Adjoint / Adjugate

সব Cofactor নিয়ে Matrix তৈরি করে সেটির Transpose নিলে Adjoint পাওয়া যায়।

সূত্র:

Adj(A) = (Cofactor Matrix)^T

2×2 উদাহরণ:

A = [
[a, b]
[c, d]
]

Adj(A) = [
[d, -b]
[-c, a]
]

---

## ৪. Determinant

Determinant হলো Square Matrix থেকে পাওয়া Scalar মান।

2×2 সূত্র:

|A| = ad − bc

উদাহরণ:

A = [
[2, 4]
[3, 5]
]

|A| = (2×5) − (3×4)

= -2

3×3 সূত্র:

|A| = a(ei−fh) − b(di−fg) + c(dh−eg)

উদাহরণ:

A = [
[10,20,30]
[40,50,60]
[70,80,90]
]

|A|

= 10(-300)

−20(-600)

+30(-300)

= 0

Determinant Rules:

1. দুই Row/Column একই হলে:

|A| = 0

2. Row/Column proportional হলে:

|A| = 0

3. কোনো Row/Column পুরো Zero হলে:

|A| = 0

4. দুই Row swap করলে:

|B| = -|A|

---

## ৫. Matrix Multiplication

শর্ত:

প্রথম Matrix-এর Column সংখ্যা = দ্বিতীয় Matrix-এর Row সংখ্যা

সূত্র:

(AB)ij = Σ(aik × bkj)

উদাহরণ:

A = [
[1,2]
[3,4]
]

B = [
[5,6]
[7,8]
]

AB = [
[19,22]
[43,50]
]

---

## ৬. Matrix Inverse

শর্ত:

|A| ≠ 0

সূত্র:

A^(-1) = (1/|A|) × Adj(A)

উদাহরণ:

A = [
[2,1]
[5,3]
]

|A| = 1

A^(-1) = [
[3,-1]
[-5,2]
]

যদি |A| = 0 হয়,

তাহলে Inverse নেই।

এটাকে Singular Matrix বলে।

---

## ৭. Transpose

Row → Column

Column → Row

উদাহরণ:

A = [
[1,2]
[3,4]
]

A^T = [
[1,3]
[2,4]
]

---

## ৮. Trace

Main Diagonal-এর উপাদানের যোগফল।

সূত্র:

Trace(A) = a11 + a22 + ...

উদাহরণ:

A = [
[1,2,3]
[4,5,6]
[7,8,9]
]

Trace = 1 + 5 + 9

= 15

---

## ৯. Eigenvalues

যে মানগুলো নিচের সমীকরণ পূরণ করে:

Ax = λx

সূত্র:

det(A − λI) = 0

উদাহরণ:

A = [
[1,2]
[3,4]
]

λ² − 5λ − 2 = 0

λ = (5 ± √33)/2

---

## ১০. Rank

Matrix-এর সবচেয়ে বেশি সংখ্যক Linearly Independent Rows বা Columns।

উদাহরণ:

A = [
[1,2,3]
[4,5,6]
[7,8,9]
]

Rank(A) = 2

B = [
[2,3]
[4,5]
]

Rank(B) = 2

---

## ১১. Condition Number

Matrix কতটা sensitive তা নির্দেশ করে।

সূত্র:

Cond(A) = ||A|| × ||A^(-1)||

যদি Inverse না থাকে:

Cond(A) = ∞

---

শর্টকাট:

Minor
→ Row + Column বাদ → Determinant

↓

Cofactor
→ Minor × (-1)^(i+j)

↓

Adjoint
→ Cofactor Matrix → Transpose

↓

Inverse
→ (1/|A|) × Adj(A)

↓

Trace
→ Diagonal Sum

↓

Eigenvalue
→ det(A − λI)

↓

Rank
→ Independent Rows সংখ্যা
