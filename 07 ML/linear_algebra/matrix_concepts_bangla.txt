# MATRIX — ALL TOPICS (Complete Roadmap)

=========================
PART-1 : INTRODUCTION
=====================

1. Matrix is a square or rectangular array of numbers, symbols, or expressions, arranged in rows and columns.

2. Order / Dimension of Matrix is the number of rows and columns in a matrix, denoted as m × n.

3. Element of Matrix is each individual item in a matrix, denoted as aᵢⱼ.

4. Matrix Notation is the way to represent a matrix, denoted as A or [aᵢⱼ].

Types of Matrix:
5. Row Matrix
     A matrix with only one row, denoted as 1 × n.
     A = [a₁, a₂, ..., aₙ]
6. Column Matrix
     A matrix with only one column, denoted as m × 1.
     A = [a₁, a₂, ..., aₘ]ᵀ

7. Rectangular Matrix
     A matrix with different number of rows and columns, denoted as m × n where m ≠ n.
     A = [aᵢⱼ]ₘₓₙ

8. Square Matrix
     A matrix with equal number of rows and columns, denoted as n × n.
     A = [aᵢⱼ]ₙₓₙ

9. Zero (Null) Matrix
     A matrix with all elements equal to zero, denoted as O or 0.
     O = [0]ₘₓₙ
     O = [
          0, 0, 0
          0, 0, 0
          0, 0, 0
          ]


10. Diagonal Matrix
     A square matrix with all non-diagonal elements equal to zero, denoted as D.
     D = [dᵢⱼ]ₙₓₙ where dᵢⱼ = 0 for i ≠ j.
     D = [
          d₁, 0, 0
          0, d₂, 0
          0, 0, d₃
          ]
     
11. Scalar Matrix
     A diagonal matrix with all diagonal elements equal to a scalar k, denoted as kI.
     kI = [kδᵢⱼ]ₙₓₙ where δᵢⱼ is the Kronecker delta.
     kI = [
          k, 0, 0
          0, k, 0
          0, 0, k
          ]
     
12. Identity (Unit) Matrix
     A scalar matrix with all diagonal elements equal to 1, denoted as I.
     I = [δᵢⱼ]ₙₓₙ where δᵢⱼ is the Kronecker delta.
     I = [
          1, 0, 0
          0, 1, 0
          0, 0, 1
          ]
     
13. Upper Triangular Matrix:
     is a square matrix where all the elements below the main diagonal are zero.
     U = [
          1, 2, 3
          0, 4, 5
          0, 0, 6
     ]     

14. Lower Triangular Matrix:
     is a square matrix where all the elements above the main diagonal are zero.
     L = [
          1, 0, 0
          2, 3, 0
          4, 5, 6
     ]     

15. Singular Matrix:
     A square matrix that does not have an inverse.
     det(A) = 0
     A = [
          1, 2
          2, 4
          ]
     det(A) = 1*4 - 2*2 = 0

16. Non-Singular Matrix:
     A square matrix that has an inverse.
     det(A) ≠ 0
     A = [
          1, 2
          3, 4
          ]
     det(A) = 1*4 - 2*3 = -2 ≠ 0


17. Symmetric Matrix:
     A square matrix that is equal to its transpose.
     A = Aᵀ
     A = [
          1, 2, 3
          2, 4, 5
          3, 5, 6
          ]

18. Skew Symmetric Matrix:
     A square matrix that is equal to the negative of its transpose.
     A = -Aᵀ
     A = [
          0, 1, 2
          -1, 0, 3
          -2, -3, 0
          ]

19. Orthogonal Matrix:
     A square matrix whose transpose is equal to its inverse.
     Aᵀ = A⁻¹
     A = [
          cos(θ), -sin(θ)
          sin(θ), cos(θ)
          ]
     Aᵀ = A⁻¹
     B = [
          cos(θ), sin(θ)
          -sin(θ), cos(θ)
          ]

PART-2 : BASIC OPERATIONS     
=========================

20. Matrix Equality
     Two matrices are equal if they have the same dimensions and corresponding elements are equal.
     A = B if and only if aᵢⱼ = bᵢⱼ for all i and j.
     A = [
          1, 2
          3, 4
          ]
     B = [
          1, 2
          3, 4
          ]
     A = B

21. Matrix Addition
     Matrix addition is defined for two matrices of the same dimensions.
     A + B = [
          a₁₁ + b₁₁, a₁₂ + b₁₂
          a₂₁ + b₂₁, a₂₂ + b₂₂
          ]
     A = [
          1, 2
          3, 4
          ]
     B = [
          5, 6
          7, 8
          ]
     A + B = [
          6, 8
          10, 12
          ]

22. Matrix Subtraction
     Matrix subtraction is defined for two matrices of the same dimensions.
     A - B = [
          a₁₁ - b₁₁, a₁₂ - b₁₂
          a₂₁ - b₂₁, a₂₂ - b₂₂
          ]
     A = [
          1, 2
          3, 4
          ]
     B = [
          5, 6
          7, 8
          ]
     A - B = [
          -4, -4
          -4, -4
          ]

23. Scalar Multiplication
     Scalar multiplication is defined for a matrix and a scalar.
     kA = [
          ka₁₁, ka₁₂
          ka₂₁, ka₂₂
          ]
     k = 2
     A = [
          1, 2
          3, 4
          ]
     kA = [
          2, 4
          6, 8
          ]

24. Matrix Multiplication
     Matrix multiplication is defined for two matrices where the number of columns in the first matrix equals the number of rows in the second matrix.
     A × B = [
          a₁₁*b₁₁ + a₁₂*b₂₁, a₁₁*b₁₂ + a₁₂*b₂₂
          a₂₁*b₁₁ + a₂₂*b₂₁, a₂₁*b₁₂ + a₂₂*b₂₂
          ]
     A = [
          1, 2
          3, 4
          ]
     B = [
          5, 6
          7, 8
          ]
     A × B = [
          1*5 + 2*7, 1*6 + 2*8
          3*5 + 4*7, 3*6 + 4*8
          ]
     A × B = [
          19, 22
          43, 50
          ]

25. Transpose of Matrix
     The transpose of a matrix is obtained by swapping rows with columns.
     Aᵀ = [
          a₁₁, a₂₁
          a₁₂, a₂₂
          ]
     A = [
          1, 2
          3, 4
          ]
     Aᵀ = [
          1, 3
          2, 4
          ]

26. Properties of Transpose
     (Aᵀ)ᵀ = A
     (A + B)ᵀ = Aᵀ + Bᵀ
     (kA)ᵀ = kAᵀ
     (AB)ᵀ = BᵀAᵀ

PART-3 : DETERMINANT
====================

27. Determinant
     The determinant of a square matrix is a scalar value that provides important information about the matrix.
     For a 2x2 matrix:
     det(A) = ad - bc
     For a 3x3 matrix:
     det(A) = a(ei - fh) - b(di - fg) + c(dh - eg)
     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     det(A) = 1*(5*9 - 6*8) - 2*(4*9 - 6*7) + 3*(4*8 - 5*7)
     det(A) = 1*(45 - 48) - 2*(36 - 42) + 3*(32 - 35)
     det(A) = 1*(-3) - 2*(-6) + 3*(-3)
     det(A) = -3 + 12 - 9
     det(A) = 0

28. Determinant Expansion
     The determinant can be expanded along any row or column.
     For a 2x2 matrix:
     det(A) = a₁₁*a₂₂ - a₁₂*a₂₁
     For a 3x3 matrix:
     det(A) = a₁₁*C₁₁ + a₁₂*C₁₂ + a₁₃*C₁₃
     where Cᵢⱼ is the cofactor of element aᵢⱼ.

29. Minor
     The minor of an element is the determinant of the submatrix obtained by deleting the row and column containing that element.
     For a 3x3 matrix:
     M₁₁ = det([
          a₂₂, a₂₃
          a₃₂, a₃₃
          ])
     M₁₂ = det([
          a₂₁, a₂₃
          a₃₁, a₃₃
          ])
     M₁₃ = det([
          a₂₁, a₂₂
          a₃₁, a₃₂
          ])
     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     M₁₁ = det([
          5, 6
          8, 9
          ])
     M₁₁ = 5*9 - 6*8 = 45 - 48 = -3

30. Cofactor
     The cofactor of an element is the minor multiplied by (-1)^(i+j).
     Cᵢⱼ = (-1)^(i+j) * Mᵢⱼ
     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     C₁₁ = (-1)^(1+1) * M₁₁ = 1 * (-3) = -3
     C₁₂ = (-1)^(1+2) * M₁₂ = -1 * (-6) = 6
     C₁₃ = (-1)^(1+3) * M₁₃ = 1 * (-3) = -3

31. Cofactor Matrix
     The cofactor matrix is formed by replacing each element with its cofactor.
     C = [
          C₁₁, C₁₂, C₁₃
          C₂₁, C₂₂, C₂₃
          C₃₁, C₃₂, C₃₃
          ]
     C₁₁ = (-1)^(1+1) * M₁₁ = 1 * (-3) = -3
     C₁₂ = (-1)^(1+2) * M₁₂ = -1 * (-6) = 6
     C₁₃ = (-1)^(1+3) * M₁₃ = 1 * (-3) = -3

     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     C = [
          -3, 6, -3
          6, -12, 6
          -3, 6, -3
          ]

32. Adjoint / Adjugate
     The adjoint (or adjugate) of a matrix is the transpose of the cofactor matrix.
     adj(A) = Cᵀ

     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     C = [
          -3, 6, -3
          6, -12, 6
          -3, 6, -3
          ]
     adj(A) = Cᵀ = [
          -3, 6, -3
          6, -12, 6
          -3, 6, -3
          ]

33. Determinant Properties
     det(A) = det(Aᵀ)
     det(AB) = det(A) * det(B)
     det(kA) = kⁿ * det(A) for an n×n matrix
     det(A⁻¹) = 1/det(A)
     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     det(A) = 1*(5*9 - 6*8) - 2*(4*9 - 6*7) + 3*(4*8 - 5*7)
     det(A) = 1*(45 - 48) - 2*(36 - 42) + 3*(32 - 35)
     det(A) = 1*(-3) - 2*(-6) + 3*(-3)
     det(A) = -3 + 12 - 9 = 0

     B = [
          1, 2
          3, 4
          ]
     det(B) = 1*4 - 2*3 = 4 - 6 = -2

34. Laplace Expansion
     A Laplace expansion (also known as cofactor expansion) 
     is a method for computing the determinant of a matrix by expanding along a row or column.

     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     det(A) = 1 * det([
          5, 6
          8, 9
          ]) - 2 * det([
          4, 6
          7, 9
          ]) + 3 * det([
          4, 5
          7, 8
          ])
     det(A) = 1 * (5*9 - 6*8) - 2 * (4*9 - 6*7) + 3 * (4*8 - 5*7)
     det(A) = 1 * (45 - 48) - 2 * (36 - 42) + 3 * (32 - 35)
     det(A) = 1 * (-3) - 2 * (-6) + 3 * (-3)
     det(A) = -3 + 12 - 9 = 0

35. Cramer's Rule
     Cramer's rule is a method for solving systems of linear equations using determinants.
     A system of linear equations can be written as AX = B, where A is the coefficient matrix, 
     X is the variable vector, and B is the constant vector.
     A = [
          1, 2
          3, 4
          ]
     X = [
          x
          y
          ]
     B = [
          b1
          b2
          ]

36. Inverse of Matrix
     The inverse of a matrix A is a matrix A⁻¹ such that A * A⁻¹ = I, where I is the identity matrix.
     A⁻¹ = (1/det(A)) * adj(A)
     A⁻¹ = (1/(ad-bc)) * [d, -b
                         -c, a]
     A = [
          1, 2
          3, 4
          ]
     A⁻¹ = (1/(1*4 - 2*3)) * [4, -2
                            -3, 1]
     A⁻¹ = (1/(-2)) * [4, -2
                     -3, 1]
     A⁻¹ = [-2, 1
           1.5, -0.5]
