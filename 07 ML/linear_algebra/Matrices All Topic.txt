PART-1 : INTRODUCTION
=====================

1. Matrix is a square or rectangular array of numbers, symbols, or expressions, arranged in rows and columns.

2. Order / Dimension of Matrix is the number of rows and columns in a matrix, denoted as m × n.

3. Element of Matrix is each individual item in a matrix, denoted as aᵢⱼ.

4. Matrix Notation is the way to represent a matrix, denoted as A or [aᵢⱼ].

Types of Matrix:
5. Row Matrix
     A matrix with only one row, denoted as 1 × n.
     A = [a₁, a₂, ..., aₙ]
6. Column Matrix
     A matrix with only one column, denoted as m × 1.
     A = [a₁, a₂, ..., aₘ]ᵀ

7. Rectangular Matrix
     A matrix with different number of rows and columns, denoted as m × n where m ≠ n.
     A = [aᵢⱼ]ₘₓₙ

8. Square Matrix
     A matrix with equal number of rows and columns, denoted as n × n.
     A = [aᵢⱼ]ₙₓₙ

9. Zero (Null) Matrix
     A matrix with all elements equal to zero, denoted as O or 0.
     O = [0]ₘₓₙ
     O = [
          0, 0, 0
          0, 0, 0
          0, 0, 0
          ]


10. Diagonal Matrix
     A square matrix with all non-diagonal elements equal to zero, denoted as D.
     D = [dᵢⱼ]ₙₓₙ where dᵢⱼ = 0 for i ≠ j.
     D = [
          d₁, 0, 0
          0, d₂, 0
          0, 0, d₃
          ]
     
11. Scalar Matrix
     A diagonal matrix with all diagonal elements equal to a scalar k, denoted as kI.
     kI = [kδᵢⱼ]ₙₓₙ where δᵢⱼ is the Kronecker delta.
     kI = [
          k, 0, 0
          0, k, 0
          0, 0, k
          ]
     
12. Identity (Unit) Matrix
     A scalar matrix with all diagonal elements equal to 1, denoted as I.
     I = [δᵢⱼ]ₙₓₙ where δᵢⱼ is the Kronecker delta.
     I = [
          1, 0, 0
          0, 1, 0
          0, 0, 1
          ]
     
13. Upper Triangular Matrix:
     is a square matrix where all the elements below the main diagonal are zero.
     U = [
          1, 2, 3
          0, 4, 5
          0, 0, 6
     ]     

14. Lower Triangular Matrix:
     is a square matrix where all the elements above the main diagonal are zero.
     L = [
          1, 0, 0
          2, 3, 0
          4, 5, 6
     ]     

15. Singular Matrix:
     A square matrix that does not have an inverse.
     det(A) = 0
     A = [
          1, 2
          2, 4
          ]
     det(A) = 1*4 - 2*2 = 0

16. Non-Singular Matrix:
     A square matrix that has an inverse.
     det(A) ≠ 0
     A = [
          1, 2
          3, 4
          ]
     det(A) = 1*4 - 2*3 = -2 ≠ 0


17. Symmetric Matrix:
     A square matrix that is equal to its transpose.
     A = Aᵀ
     A = [
          1, 2, 3
          2, 4, 5
          3, 5, 6
          ]

18. Skew Symmetric Matrix:
     A square matrix that is equal to the negative of its transpose.
     A = -Aᵀ
     A = [
          0, 1, 2
          -1, 0, 3
          -2, -3, 0
          ]

19. Orthogonal Matrix:
     A square matrix whose transpose is equal to its inverse.
     Aᵀ = A⁻¹
     A = [
          cos(θ), -sin(θ)
          sin(θ), cos(θ)
          ]
     Aᵀ = A⁻¹
     B = [
          cos(θ), sin(θ)
          -sin(θ), cos(θ)
          ]

PART-2 : BASIC OPERATIONS     
=========================

20. Matrix Equality
     Two matrices are equal if they have the same dimensions and corresponding elements are equal.
     A = B if and only if aᵢⱼ = bᵢⱼ for all i and j.
     A = [
          1, 2
          3, 4
          ]
     B = [
          1, 2
          3, 4
          ]
     A = B

21. Matrix Addition
     Matrix addition is defined for two matrices of the same dimensions.
     A + B = [
          a₁₁ + b₁₁, a₁₂ + b₁₂
          a₂₁ + b₂₁, a₂₂ + b₂₂
          ]
     A = [
          1, 2
          3, 4
          ]
     B = [
          5, 6
          7, 8
          ]
     A + B = [
          6, 8
          10, 12
          ]

22. Matrix Subtraction
     Matrix subtraction is defined for two matrices of the same dimensions.
     A - B = [
          a₁₁ - b₁₁, a₁₂ - b₁₂
          a₂₁ - b₂₁, a₂₂ - b₂₂
          ]
     A = [
          1, 2
          3, 4
          ]
     B = [
          5, 6
          7, 8
          ]
     A - B = [
          -4, -4
          -4, -4
          ]

23. Scalar Multiplication
     Scalar multiplication is defined for a matrix and a scalar.
     kA = [
          ka₁₁, ka₁₂
          ka₂₁, ka₂₂
          ]
     k = 2
     A = [
          1, 2
          3, 4
          ]
     kA = [
          2, 4
          6, 8
          ]

24. Matrix Multiplication
     Matrix multiplication is defined for two matrices where the number of columns in the first matrix equals the number of rows in the second matrix.
     A × B = [
          a₁₁*b₁₁ + a₁₂*b₂₁, a₁₁*b₁₂ + a₁₂*b₂₂
          a₂₁*b₁₁ + a₂₂*b₂₁, a₂₁*b₁₂ + a₂₂*b₂₂
          ]
     A = [
          1, 2
          3, 4
          ]
     B = [
          5, 6
          7, 8
          ]
     A × B = [
          1*5 + 2*7, 1*6 + 2*8
          3*5 + 4*7, 3*6 + 4*8
          ]
     A × B = [
          19, 22
          43, 50
          ]

25. Transpose of Matrix
     The transpose of a matrix is obtained by swapping rows with columns.
     Aᵀ = [
          a₁₁, a₂₁
          a₁₂, a₂₂
          ]
     A = [
          1, 2
          3, 4
          ]
     Aᵀ = [
          1, 3
          2, 4
          ]

26. Properties of Transpose
     (Aᵀ)ᵀ = A
     (A + B)ᵀ = Aᵀ + Bᵀ
     (kA)ᵀ = kAᵀ
     (AB)ᵀ = BᵀAᵀ

PART-3 : DETERMINANT
====================

27. Determinant
     The determinant of a square matrix is a scalar value that provides important information about the matrix.
     For a 2x2 matrix:
     det(A) = ad - bc
     For a 3x3 matrix:
     det(A) = a(ei - fh) - b(di - fg) + c(dh - eg)
     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     det(A) = 1*(5*9 - 6*8) - 2*(4*9 - 6*7) + 3*(4*8 - 5*7)
     det(A) = 1*(45 - 48) - 2*(36 - 42) + 3*(32 - 35)
     det(A) = 1*(-3) - 2*(-6) + 3*(-3)
     det(A) = -3 + 12 - 9
     det(A) = 0

28. Determinant Expansion
     The determinant can be expanded along any row or column.
     For a 2x2 matrix:
     det(A) = a₁₁*a₂₂ - a₁₂*a₂₁
     For a 3x3 matrix:
     det(A) = a₁₁*C₁₁ + a₁₂*C₁₂ + a₁₃*C₁₃
     where Cᵢⱼ is the cofactor of element aᵢⱼ.

29. Minor
     The minor of an element is the determinant of the submatrix obtained by deleting the row and column containing that element.
     For a 3x3 matrix:
     M₁₁ = det([
          a₂₂, a₂₃
          a₃₂, a₃₃
          ])
     M₁₂ = det([
          a₂₁, a₂₃
          a₃₁, a₃₃
          ])
     M₁₃ = det([
          a₂₁, a₂₂
          a₃₁, a₃₂
          ])
     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     M₁₁ = det([
          5, 6
          8, 9
          ])
     M₁₁ = 5*9 - 6*8 = 45 - 48 = -3

30. Cofactor
     The cofactor of an element is the minor multiplied by (-1)^(i+j).
     Cᵢⱼ = (-1)^(i+j) * Mᵢⱼ
     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     C₁₁ = (-1)^(1+1) * M₁₁ = 1 * (-3) = -3
     C₁₂ = (-1)^(1+2) * M₁₂ = -1 * (-6) = 6
     C₁₃ = (-1)^(1+3) * M₁₃ = 1 * (-3) = -3

31. Cofactor Matrix
     The cofactor matrix is formed by replacing each element with its cofactor.
     C = [
          C₁₁, C₁₂, C₁₃
          C₂₁, C₂₂, C₂₃
          C₃₁, C₃₂, C₃₃
          ]
     C₁₁ = (-1)^(1+1) * M₁₁ = 1 * (-3) = -3
     C₁₂ = (-1)^(1+2) * M₁₂ = -1 * (-6) = 6
     C₁₃ = (-1)^(1+3) * M₁₃ = 1 * (-3) = -3

     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     C = [
          -3, 6, -3
          6, -12, 6
          -3, 6, -3
          ]

32. Adjoint / Adjugate
     The adjoint (or adjugate) of a matrix is the transpose of the cofactor matrix.
     adj(A) = Cᵀ

     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     C = [
          -3, 6, -3
          6, -12, 6
          -3, 6, -3
          ]
     adj(A) = Cᵀ = [
          -3, 6, -3
          6, -12, 6
          -3, 6, -3
          ]

33. Determinant Properties
     det(A) = det(Aᵀ)
     det(AB) = det(A) * det(B)
     det(kA) = kⁿ * det(A) for an n×n matrix
     det(A⁻¹) = 1/det(A)
     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     det(A) = 1*(5*9 - 6*8) - 2*(4*9 - 6*7) + 3*(4*8 - 5*7)
     det(A) = 1*(45 - 48) - 2*(36 - 42) + 3*(32 - 35)
     det(A) = 1*(-3) - 2*(-6) + 3*(-3)
     det(A) = -3 + 12 - 9 = 0

     B = [
          1, 2
          3, 4
          ]
     det(B) = 1*4 - 2*3 = 4 - 6 = -2

34. Laplace Expansion
     A Laplace expansion (also known as cofactor expansion) 
     is a method for computing the determinant of a matrix by expanding along a row or column.

     A = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]
     det(A) = 1 * det([
          5, 6
          8, 9
          ]) - 2 * det([
          4, 6
          7, 9
          ]) + 3 * det([
          4, 5
          7, 8
          ])
     det(A) = 1 * (5*9 - 6*8) - 2 * (4*9 - 6*7) + 3 * (4*8 - 5*7)
     det(A) = 1 * (45 - 48) - 2 * (36 - 42) + 3 * (32 - 35)
     det(A) = 1 * (-3) - 2 * (-6) + 3 * (-3)
     det(A) = -3 + 12 - 9 = 0

35. Cramer's Rule
     Cramer's rule is a method for solving systems of linear equations using determinants.
     A system of linear equations can be written as AX = B, where A is the coefficient matrix, 
     X is the variable vector, and B is the constant vector.
     A = [
          1, 2
          3, 4
          ]
     X = [
          x
          y
          ]
     B = [
          b1
          b2
          ]

36. Inverse of Matrix
     The inverse of a matrix A is a matrix A⁻¹ such that A * A⁻¹ = I, where I is the identity matrix.
     A⁻¹ = (1/det(A)) * adj(A)
     A⁻¹ = (1/(ad-bc)) * [d, -b
                         -c, a]
     A = [
          1, 2
          3, 4
          ]
     A⁻¹ = (1/(1*4 - 2*3)) * [4, -2
                            -3, 1]
     A⁻¹ = (1/(-2)) * [4, -2
                     -3, 1]
     A⁻¹ = [-2, 1
           1.5, -0.5]
     


37. Singular Matrix
     A Singular matrix is a square matrix whose determinant is 0.
     A = [
          1, 2
          2, 4
          ]
     det(A) = 1*4 - 2*2 = 4 - 4 = 0

38. Non-Singular Matrix
     A Non-Singular matrix is a square matrix whose determinant is not 0.
     A = [
          1, 2
          3, 4
          ]
     det(A) = 1*4 - 2*3 = 4 - 6 = -2

39. Adjoint Method
     A Adjoint method is a method for finding the inverse of a matrix.
     A = [
          1, 2
          3, 4
          ]
     adj(A) = [4, -2
              -3, 1]
     A⁻¹ = (1/det(A)) * adj(A)
     A⁻¹ = (1/(-2)) * [4, -2
                      -3, 1]
     A⁻¹ = [-2, 1
           1.5, -0.5]

40. Elementary Method
     A Elementary method is a method for finding the inverse of a matrix.
     A = [
          1, 2
          3, 4
          ]
     [A|I] = [1, 2, 1, 0
             3, 4, 0, 1]

          
     Step 1:
     R₂ → R₂ - 3R₁
     R₁ → R₁
     [
     1, 2, 1, 0
     0, -2, -3, 1
     ]

     Step 2:
     R₂ → R₂ / (-2)
     R₁ → R₁ - 2R₂
     [
     1, 0, 4, -1
     0, 1, 3/2, -1/2
     ]

     A⁻¹ = [-2, 1
           1.5, -0.5]

41. Row Operation
     A Row operation is an operation performed on a row of a matrix.
     There are three types of row operations:
     1. Row swapping
          A = [
               1, 2
               3, 4
               ]
          swap(R₁, R₂)
          A = [
               3, 4
               1, 2
               ]

          B = [
               1, 2, 3
               4, 5, 6
               7, 8, 9
               ]
          swap(R₁, R₂, R₃)
          B = [
               7, 8, 9
               4, 5, 6
               1, 2, 3
               ]

     2. Row multiplication
          A = [
               1, 2
               3, 4
               ]
     multiply(R₁, 2)
          A = [
               2, 4
               3, 4
               ]

     3. Row addition
          A = [
               1, 2
               3, 4
               ]
     add(R₁, R₂)
          A = [
               1, 2
               4, 6
               ]

42. Column Operation
     A Column operation is an operation performed on a column of a matrix.
     There are three types of column operations:
     1. Column swapping
          A = [1, 2, 3
               4, 5, 6
               7, 8, 9]
          swap(C₁, C₂)
          A = [2, 1, 3
               5, 4, 6
               8, 7, 9]

     2. Column multiplication
          A = [1, 2
               3, 4]
          multiply(C₁, 2)
          A = [2, 2
               6, 4]

     3. Column addition
          A = [1, 2
               3, 4]
          add(C₁, C₂)
          A = [1, 3
               3, 7]

43. Elementary Matrix
     An Elementary matrix is a matrix that is obtained by performing a single elementary operation on an identity matrix.
     There are three types of elementary matrices:
     1. Row swapping
          A = [
               1, 0
               0, 1
               ]
          swap(C₁, C₂)
          A = [
               0, 1
               1, 0
               ]

     2. Row multiplication
          A = [
               1, 0
               0, 1
               ]
          multiply(C₁, 2)
          A = [
               2, 0
               0, 1
               ]

     3. Row addition
          A = [
               1, 0
               0, 1
               ]
          add(C₁, C₂)
          A = [
               1, 0
               1, 1
               ]

44. Row Echelon Form (REF)
     A Row Echelon Form is a matrix that satisfies the following conditions:
     1. All non-zero rows are above all zero rows.
     
     A = [
          1, 2, 3
          0, 4, 5
          0, 0, 6
          ]

     2. Each leading entry of a row is in a column to the right of the leading entry of the row above it.

     A = [
          1, 2, 3
          0, 4, 5
          0, 0, 6
          ]

     3. All entries in a column below a leading entry are zeros.
     
     A = [
          1, 2, 3
          0, 4, 5
          0, 0, 6
          ]

45. Reduced Row Echelon Form (RREF)
     A Reduced Row Echelon Form is a matrix that satisfies the following conditions:
     1. All non-zero rows are above all zero rows.
     A = [
          1, 0, 0
          0, 1, 0
          0, 0, 1
          ]

     2. Each leading entry of a row is in a column to the right of the leading entry of the row above it.
     A = [
          1, 0, 0
          0, 1, 0
          0, 0, 1
          ]

     3. All entries in a column below a leading entry are zeros.
     A = [
          1, 0, 0
          0, 1, 0
          0, 0, 1
          ]

     4. The leading entry in each non-zero row is 1.
     A = [
          1, 0, 0
          0, 1, 0
          0, 0, 1
          ]

     5. Each leading 1 is the only non-zero entry in its column.
     A = [
          1, 0, 0
          0, 1, 0
          0, 0, 1
          ]

46. Rank of Matrix
     A Matrix Rank is the maximum number of linearly independent rows or columns in a matrix.
     When the determinant is not zero, the matrix is said to be full rank.
     But when the determinant is zero, the matrix is said to be rank deficient.

     A = [
          1, 2
          3, 4
          ]

     The rank of this matrix is 2.
     Because all rows are linearly independent.
     
     B = [
          1, 2, 3
          4, 5, 6
          7, 8, 9
          ]

     The rank of this matrix is 2.
     Because the second row is a linear combination of the first row.

     C = [
          1, 2, 3
          0, 4, 5
          0, 0, 6
          ]

     The rank of this matrix is 3.
     Because all rows are linearly independent.

47. Rank using Row Reduction
     To find the rank of a matrix using row reduction, we need to reduce the matrix to row echelon form and count the number of non-zero rows.

     A = [ 1, 2, 3 4, 5, 6 7, 8, 9]

     Step 1: R₂ → R₂ - 4R₁ 
     R₂ = [4 5 6] - 4[1 2 3] = [0 -3 -6]

     Step 2: R₃ → R₃ - 7R₁ 
     R₃ = [7 8 9] - 7[1 2 3] = [0 -6 -12]

     Matrix: [ 1 2 3 0 -3 -6 0 -6 -12]

     Step 3: R₃ → R₃ - 2R₂

     R₃ = [0 -6 -12] - 2[0 -3 -6] = [0 0 0]

     Final Matrix: [ 1 2 3 0 -3 -6 0 0 0]

     Non-zero row = 2

     Therefore, Rank(A) = 2

48. Rank using Determinant
     A = [ 1, 2, 3 4, 5, 6 7, 8, 9]

     Step 1: Calculate the determinant of the matrix.
     det(A) = 1(5*9 - 6*8) - 2(4*9 - 6*7) + 3(4*8 - 5*7)
     det(A) = 1(45 - 48) - 2(36 - 42) + 3(32 - 35)
     det(A) = 1(-3) - 2(-6) + 3(-3)
     det(A) = -3 + 12 - 9
     det(A) = 0

     Since the determinant is 0, the matrix is rank deficient.
     Therefore, Rank(A) = 2

49. System of Linear Equations
     A system of linear equations is a set of two or more linear equations involving the same set of variables.

     Example:
     x + 2y + 3z = 6
     4x + 5y + 6z = 15
     7x + 8y + 9z = 24
     


50. Matrix Representation
     A MATRIX REPRESENTATION OF A SYSTEM OF LINEAR EQUATIONS IS A WAY TO EXPRESS THE SYSTEM IN MATRIX FORM.
     Matrix Form:
     [1 2 3] [x]   [6]
     [4 5 6] [y] = [15]
     [7 8 9] [z]   [24]
     
     AX = B

51. Gaussian Elimination
     Gaussian elimination is a method for solving systems of linear equations by transforming the coefficient matrix into row echelon form.

     Example:
     x + 2y + 3z = 6
     4x + 5y + 6z = 15
     7x + 8y + 9z = 24
     
     Matrix Form:
     [1 2 3] [x]   [6]
     [4 5 6] [y] = [15]
     [7 8 9] [z]   [24]
     
     After Gaussian elimination, we get:
     [1 2 3] [x]   [6]
     [0 -3 -6] [y] = [3]
     [0 0 0] [z]   [0]
     
     This is called row echelon form.
     


52. Gauss-Jordan Elimination
     Gauss-Jordan elimination is a method for solving systems of linear equations by transforming the coefficient matrix into reduced row echelon form.


     Example:
     x + 2y + 3z = 6
     4x + 5y + 6z = 15
     7x + 8y + 9z = 24
     
     Matrix Form:
     [1 2 3] [x]   [6]
     [4 5 6] [y] = [15]
     [7 8 9] [z]   [24]
     
     After Gauss-Jordan elimination, we get:
     [1 0 0] [x]   [1]
     [0 1 0] [y] = [2]
     [0 0 1] [z]   [3]
     
     This is called reduced row echelon form.
     
53. LU Decomposition
     LU decomposition is a method for solving systems of linear equations by decomposing the coefficient matrix into a lower triangular matrix and an upper triangular matrix.

     Example:
     x + 2y + 3z = 6
     4x + 5y + 6z = 15
     7x + 8y + 9z = 24
     
     Matrix Form:
     [1 2 3] [x]   [6]
     [4 5 6] [y] = [15]
     [7 8 9] [z]   [24]
     
     After LU decomposition, we get:
     L = [1 0 0]    U = [1 2 3]
         [4 1 0]        [0 -3 -6]
         [7 2 1]        [0 0 0]
     
     This is called LU decomposition.

54. Characteristic Equation
     A characteristic equation is an equation that is used to find the eigenvalues of a matrix.
     |A - λI| = 0

     A = Given Square Matrix

     λ = Eigenvalue

     I = Identity Matrix

     A = [a b]
         [c d]

     I = [1 0]
         [0 1]
     
     So:
          A - λI = [a-λ b]
                   [c d-λ]
     
     Now:
          |A - λI| = (a-λ)(d-λ) - bc = 0
     
     This is the characteristic equation.
     
     Solving this equation gives us the eigenvalues.
     A = [
          2 1
          1 2
          ]

     |A-λI| = |2-λ 1| |1 2-λ|

          ⇒ (2-λ)(2-λ) - 1 = 0

          ⇒ 4 - 4λ + λ² - 1 = 0

          ⇒ λ² - 4λ + 3 = 0

          ⇒ (λ-1)(λ-3)=0

          Eigenvalues:

          λ = 1, 3

55. Eigenvalue
     An eigenvalue is a scalar that represents the factor by which a linear transformation scales a vector.
     

56. Eigenvector
     An eigenvector is a non-zero vector that, when multiplied by a matrix, results in a scalar multiple of itself.

57. Characteristic Polynomial
     The characteristic polynomial of a matrix is the polynomial obtained by taking the determinant of the matrix minus a scalar multiple of the identity matrix.

58. Diagonalization
     Diagonalization is the process of finding a diagonal matrix that is similar to a given matrix.

59. Trace
     The trace of a square matrix is the sum of the elements on its main diagonal.

60. Matrix Norm
     A matrix norm is a function that assigns a strictly positive length or size to each matrix.

     The condition number of a matrix is a measure of how sensitive the solution of a system of linear equations is to small changes in the data.

62. Positive Definite Matrix
     A positive definite matrix is a symmetric matrix that has all positive eigenvalues.

63. Sparse Matrix
     A sparse matrix is a matrix in which most of the elements are zero.

64. Dense Matrix
     A dense matrix is a matrix in which most of the elements are non-zero.

65. Block Matrix
     A block matrix is a matrix that is partitioned into submatrices, or blocks.
