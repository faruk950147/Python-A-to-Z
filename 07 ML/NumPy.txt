NumPy – All Important Methods with Description (Beginner → Advanced)

NumPy হলো Python-এর numerical computing লাইব্রেরি। এটি মূলত ndarray (N-dimensional array) ব্যবহার করে দ্রুত গণনা করতে সাহায্য করে।

নিচে category অনুযায়ী গুরুত্বপূর্ণ methods + সংক্ষিপ্ত বর্ণনা দেওয়া হলো 👇

1. Array Creation Methods
Method	Description
np.array()	Python list/tuple থেকে array তৈরি করে
np.zeros(shape)	নির্দিষ্ট shape এর সবগুলো মান 0
np.ones(shape)	সব মান 1
np.empty(shape)	random/garbage value সহ array
np.full(shape, value)	নির্দিষ্ট value দিয়ে পূর্ণ array
np.arange(start, stop, step)	range অনুযায়ী array
np.linspace(start, stop, num)	সমান দূরত্বে নির্দিষ্ট সংখ্যক মান
np.logspace()	log scale এ মান তৈরি
np.eye(n)	identity matrix
np.identity(n)	identity matrix (same as eye)
np.diag()	diagonal matrix তৈরি বা বের করা
2. Array Attributes (Properties)
Attribute	Description
arr.shape	array এর dimension structure
arr.ndim	কয় dimension
arr.size	মোট element সংখ্যা
arr.dtype	data type
arr.itemsize	প্রতি element এর byte size
3. Reshaping Methods
Method	Description
arr.reshape()	shape পরিবর্তন
arr.flatten()	1D array বানায় (copy তৈরি করে)
arr.ravel()	1D বানায় (view হতে পারে)
arr.resize()	shape inplace পরিবর্তন
np.expand_dims()	নতুন axis যোগ করে
np.squeeze()	extra axis সরায়
arr.T	transpose
np.transpose()	row ↔ column পরিবর্তন
