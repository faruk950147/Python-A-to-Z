Matplotlib – Beginner to Advanced Roadmap (Python)

Matplotlib হলো Python-এর সবচেয়ে জনপ্রিয় data visualization library। তুমি যেহেতু Python জানো, তাই এটা শেখা তোমার জন্য অনেক সহজ হবে।

আমি এখানে Beginner → Intermediate → Advanced → Project Level পুরো roadmap দিচ্ছি।

Beginner Level
Install & Basic Setup

pip install matplotlib
import matplotlib.pyplot as plt

x-axis = horizontal

y-axis = vertical

Add Title, Labels, Grid
plt.plot(x, y)
plt.title("Simple Line Chart")
plt.xlabel("X Axis")
plt.ylabel("Y Axis")
plt.grid(True)
plt.show()

Marker & Line Style
plt.plot(x, y, marker='o', linestyle='--')
plt.show()

Intermediate Level
Bar Chart
categories = ["A", "B", "C"]
values = [5, 7, 3]

plt.bar(categories, values)
plt.title("Bar Chart")
plt.show()

Horizontal Bar
plt.barh(categories, values)
plt.show()

Pie Chart
sizes = [40, 30, 20, 10]
labels = ["A", "B", "C", "D"]

plt.pie(sizes, labels=labels, autopct="%1.1f%%")
plt.show()
Scatter Plot is relation
x = [1,2,3,4,5]
y = [5,7,8,5,6]

plt.scatter(x, y)
plt.show()

Multiple Lines
plt.plot(x, y, label="Line 1")
plt.plot(x, [3,4,5,6,7], label="Line 2")
plt.legend()
plt.show()

Advanced Level
Subplots
plt.subplot(1,2,1)
plt.plot(x, y)

plt.subplot(1,2,2)
plt.bar(categories, values)

plt.show()

Figure Size
plt.figure(figsize=(8,5))
plt.plot(x, y)
plt.show()

Histogram
import numpy as np

data = np.random.randn(1000)
plt.hist(data, bins=30)
plt.show()

Custom Style
plt.style.use("ggplot")
plt.plot(x, y)
plt.show()

Save Chart as Image
plt.plot(x, y)
plt.savefig("chart.png")
plt.show()

Object-Oriented Approach (Professional Way)

Professional coding এ এটা ব্যবহার করা হয়।

fig, ax = plt.subplots()

ax.plot(x, y)
ax.set_title("OOP Style Plot")
ax.set_xlabel("X")
ax.set_ylabel("Y")

plt.show()

Real World Example (With Pandas)
import pandas as pd
import matplotlib.pyplot as plt

data = {
    "Month": ["Jan", "Feb", "Mar"],
    "Sales": [100, 150, 120]
}

df = pd.DataFrame(data)
df.plot(x="Month", y="Sales", kind="line")
plt.show()
