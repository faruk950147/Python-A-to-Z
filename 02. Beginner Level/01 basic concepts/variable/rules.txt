"""
================================
    Python Variables - Notes
================================

What is a Variable?
------------------
A variable is a container used to store data in memory.

Example:
    name = "Faruk"
    age = 20

------------------
Variable Naming Rules
------------------

1. Variable name must start with a letter or underscore (_)
    - name
    - _userName

2. Variable name cannot start with a number
    - user1   ✔
    - 1user   ✘

3. Variable name can contain only letters, numbers, and underscores
    - total_marks   ✔
    - total-marks   ✘

4. Variable names are case-sensitive
    - age ≠ Age ≠ AGE

5. Python keywords cannot be used as variable names
    - class   ✘
    - for     ✘
    - if      ✘

------------------
Variable Naming Conventions
------------------

1. Snake Case (Most Recommended in Python)
    - my_variable_name
    - total_price
    - user_email

2. Camel Case (Less common, sometimes used)
    - myVariableName
    - totalPrice

3. Pascal Case (Used for Class Names)
    - MyVariableName
    - StudentProfile

------------------
Best Practices
------------------
- Always use snake_case for variables
- Use meaningful variable names
- Use PascalCase for class names
- Avoid single-letter variable names except in loops
"""
