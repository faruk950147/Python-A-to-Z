Callback Function & Higher Order Function Notes

1. Callback Function

Definition: Callback Function হলো এমন একটি function যেটিকে অন্য একটি
function-এর মধ্যে argument হিসেবে পাঠানো হয় এবং সেই function-এর ভিতরে
execute করা হয়।

Simple Explanation: একটি function আরেকটি function-কে বলে — “আমার কাজের
সময় তুমি এই functionটা চালাবে।”

Example:

def simple(a, b, callback): 
    return callback(a, b)

def add(a, b): 
    return a + b

print(simple(10, 20, add)) # 30

এখানে add() হলো Callback Function।

2. Higher Order Function

Definition: Higher Order Function হলো এমন function: - যেটা অন্য
function-কে argument হিসেবে নেয় অথবা - একটি function return করে

Simple Explanation: যে function, function নিয়ে কাজ করে — সেটাই Higher
Order Function।

Example:

def simple(a, b, callback): 
    return callback(a, b)

এখানে simple() হলো Higher Order Function।

3. Callback vs Higher Order Function

Callback Function: - Argument হিসেবে পাঠানো হয় - অন্য function-এর ভিতরে
execute হয়

Higher Order Function: - Function কে argument হিসেবে নেয় - Function
return করতে পারে

4. Built-in Higher Order Function Example

numbers = [1, 2, 3, 4]

result = list(map(lambda x: x * 2, numbers)) 
print(result) # [2, 4, 6, 8]

এখানে: map() → Higher Order Function lambda → Callback Function

Important Points:

✔ Function কে argument হিসেবে পাঠানো যায় ✔ Function return করা যায় ✔
Callback = Passed Function ✔ Higher Order = Takes/Returns Function
